# Pretrained weights

YOLOFuse26 initializes from official single-modality YOLO26 checkpoints. Training downloads `weights/yolo26{scale}.pt` through Ultralytics when the file is missing; provide `--weights /path/to/yolo26n.pt` to use an existing local file.

The pretrained checkpoint scale must match `--scale`. `fusion_weights.initialize_from_yolo26` maps backbone and neck layers by their roles in the graph, initializes both modality branches and detection heads, and leaves dataset classification outputs freshly initialized. For data-level fusion, it expands the first convolution to six channels.

Use `--scratch` to disable pretrained initialization. Resume only checkpoints generated by YOLOFuse26; old YOLOFuse checkpoints use a different architecture.

Fully trained RGB+IR fusion checkpoints are not included. Downloaded checkpoints, exported models, and local experiments are excluded by `.gitignore`.

Upstream: [Ultralytics YOLO26](https://docs.ultralytics.com/models/yolo26/), [official release assets](https://github.com/ultralytics/assets/releases/tag/v8.4.0).
